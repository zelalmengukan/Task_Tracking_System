# Task_Tracking_System
A Terminal-based To-Do application built with core Python concepts (functions, lists, loops).

📌 Features
Add Task: Instantly adds new tasks to the active to-do list.
Listing: Neatly displays active tasks with their index numbers.
Task Completion: Removes completed tasks from the main list and moves them to the archive.
Error Handling: Prevents program crashes on invalid user inputs.
